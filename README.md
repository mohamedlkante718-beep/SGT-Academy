# SGT Academy

Plateforme professionnelle de formation en ligne (e-learning) de **Safe Green Tech**.

> « Bâtissons un avenir meilleur »

Lancement au Mali, conçue dès le départ pour être accessible dans plusieurs pays d'Afrique francophone (Sénégal, Côte d'Ivoire, Burkina Faso, Guinée, Niger, Bénin, Togo, Cameroun...).

## Statut

Projet en phase de cadrage. Voir [`docs/01-ANALYSE-ARCHITECTURE.md`](docs/01-ANALYSE-ARCHITECTURE.md) pour l'analyse complète et l'architecture technique avant tout développement.

## Structure prévue

```
sgt-academy/
├── docs/            # documentation et guides
├── backend/         # Django + Django REST Framework
├── frontend-web/    # Next.js (site public, SEO)
└── mobile/          # Flutter (mobile + web authentifié)
```
